# smokefire 1.0.0 Deployment Delivery

Deployment and user-delivery repository for the fire, smoke, and smoking AI-assisted video alerting system from Shenzhen Dudumiao Technology Co., Ltd.

This repository remains **PRIVATE** and does not contain the project source tree. Release `v1.0.0` provides prebuilt CPU and NVIDIA GPU offline packages, both model weights, lifecycle and verification scripts, and all six Chinese/English manuals.

## Release assets

- `smokefire-deploy-1.0.0-cpu.zip`: complete CPU offline bundle, including the smokefire and go2rtc images and both weights;
- `smokefire-deploy-1.0.0-gpu.zip`: NVIDIA GPU bundle containing both weights, scripts, configuration, and manuals;
- `smokefire-images.tar.gz.partNN`: every GPU image part; all parts are required with the GPU bundle;
- `fire_smoke_v5.pt` and `smoking_v4.pt`: separately downloadable weight backups;
- `SHA256SUMS-v1.0.0.txt`: SHA-256 hashes for all Release assets.

## Quick start

CPU: download and extract `smokefire-deploy-1.0.0-cpu.zip`, then run `start.ps1` on Windows or `start.sh` on Linux.

GPU: download and extract `smokefire-deploy-1.0.0-gpu.zip`, place every `smokefire-images.tar.gz.partNN` asset in the extracted `images/` directory, then run the start script. The GPU host must already have the NVIDIA driver, Docker, and NVIDIA Container Toolkit.

Open `http://127.0.0.1:8600` on the service host after startup.

## Video stream integration

The bundle supports direct camera/NVR RTSP URLs, the bundled go2rtc fan-out service, and an existing customer-managed go2rtc instance. For the existing-go2rtc mode, configure one API base and one RTSP base; smokefire reads `GET /api/streams` and imports all main streams automatically, so users do not enter cameras one by one.

For an existing go2rtc instance on the same host, the container-side addresses are usually:

```text
API  http://host.docker.internal:1984
RTSP rtsp://host.docker.internal:8554
```

See the Deployment Guide for commands, sub-stream filtering, deletion, and restoration behavior.
