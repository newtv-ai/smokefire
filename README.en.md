# smokefire 1.0.0 Deployment Delivery

Deployment and user-delivery repository for the fire, smoke, and smoking AI-assisted video alerting system from Shenzhen Dudumiao Technology Co., Ltd.

This repository does not contain the project source tree. Release `v1.0.0` provides the runnable delivery assets:

- `smokefire-deploy-1.0.0-cpu.zip`: complete standalone CPU deployment bundle;
- `fire_smoke_v5.pt`: fire/smoke model weight;
- `smoking_v4.pt`: smoking model weight.

## Quick start

1. Download and extract `smokefire-deploy-1.0.0-cpu.zip` from Releases.
2. Run `start.ps1` on Windows or `start.sh` on Linux.
3. Open `http://127.0.0.1:8600` on the service host.

Read the deployment, operation, and model capability PDFs under `docs/` before installation and acceptance. smokefire is an AI-assisted alerting tool and does not replace statutory fire protection, human patrols, emergency procedures, or on-site verification.
