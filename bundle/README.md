# Deployment bundle template

This directory shows the lifecycle scripts and Docker Compose configuration included in the `v1.0.0` standalone package. It intentionally does not contain the Docker image or model weights.

For a runnable installation, download `smokefire-deploy-1.0.0-cpu.zip` from GitHub Releases. That archive includes this template, `SHA256SUMS`, the prebuilt image, both weights, and all six PDF manuals.

本目录用于展示 `v1.0.0` 独立部署包中的启停脚本和 Compose 配置，故意不存放 Docker 镜像与模型权重。需要实际部署时，请从 GitHub Releases 下载 `smokefire-deploy-1.0.0-cpu.zip`；完整 ZIP 已包含校验清单、镜像、两个权重和 6 份 PDF 手册。
